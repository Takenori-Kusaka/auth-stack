## 0. 結論

1. 種資料に挙がった 14 件のすべてについて一次報告を確認できた [D]（§1.2）。ただし MGM の侵入経路は一次報告で確認できないため、MGM の項は CISA・FBI の共同勧告 AA23-320A が記す Scattered Spider の手口だけを写像の根拠にした [D]（RS-12#48〜#52 から導出）[^22][^23]。Storm-0558 の鍵の入手経路も未確定のままである [I][^1][^2]（RS-12#7）。
2. 侵害事故 10 件で破られた前提は、6 つの類型に集約できる [D]（§2.1）。(a) 鍵・token と issuer・テナントの結合不足、(b) 非本番・レガシー・内部経路が統制の外にあること、(c) MFA を通過した後の session・資格情報の窃取、(d) support・ヘルプデスク経路、(e) 第三者連携の grant、(f) 可変属性によるアカウント連結、の 6 つである [D]。
3. 可用性事故 4 件は、どれも外部からの攻撃ではなく、事業者自身の自動化・スクリプト・配信が起点だった [I][^24][^25][^26][^27]。そのうち Google、Azure AD、CrowdStrike の 3 件は変更が全域に同時に届き、Atlassian は 1 回のスクリプト実行で 883 サイトを削除した [I][^24][^25][^26][^27]。攻撃者モデル DL-51 の 12 類型のうち可用性に関わるものは「リージョン障害」だけで、この型の事故を表せない [D]。DL-51 には「自社・供給者の変更と自動化の誤り」を非敵対の類型として追加するよう提案する [D]（§6.4）。
4. 署名鍵については、一次報告に二方向のリスクが記録されている [I][^1][^25]。一つは鍵を回さないリスク（Storm-0558 では 2016 年作成の鍵が 2023 年まで有効だった）、もう一つは回転・削除の操作そのものが基盤を止めるリスク（Azure AD 2021-03-15 の鍵誤削除と、CSRB が認定した 2021 年の手動回転に関連する大規模障害）である [I][^1][^25]。このため、自動回転・鍵年齢の監視・cell 単位の段階展開・削除前の保持状態の検査は、別々にではなく一体の要件（CB-REQ-02、CB-REQ-03）として ADR-007 と ADR-013 に渡す [D]。
5. 14 件のうち、事業者自身が最初に検知したことが一次報告で確認できたのは 4 件で、6 件は顧客・被害組織・研究者など外部が起点だった [D]（§2.2。一次報告の記述からの集計）。Storm-0558 で検知に使われたログは上位の有償ライセンスがなければ使えず [I][^1]、Okta では別種のログイベントとして記録されていたため 14 日間ダウンロードを特定できなかった [I][^9]。顧客が読める監査ログを既定で提供すること（決裁案 DA-1）と、自力検知比率の KRI（CB-KRI-10）を提案する [D]。
6. 本書は要件候補 28 件（CB-REQ）、KRI 候補 16 件（CB-KRI）、負例試験・演習候補 20 件（CB-TC）を後続の ADR・DL に渡す [D]。閾値はすべて TBD とし、TC の採番・事前登録・実測は DL-22・DL-81 で行う [D]。G-081・R-168・R-173 は実測（区分 C）が必要で、本書だけでは閉じない [D]。
7. 経営・事業・法務の判断が要る 5 点（顧客向け監査ログ、損失シナリオの追加、第三者連携の契約条件、公表・訂正方針、テナント管理者へのフィッシング耐性認証の義務化）を決裁案として §7 に示す [D]。いずれも未決定である [D]。

## 2. 横断所見

### 2.1 破られた前提の類型

| 類型 | 破られた前提（本書の解釈） | 該当する事故 | 一次報告の要点 | 主な要件候補 |
|---|---|---|---|---|
| (a) 鍵・token の結合不足 | 「検証ライブラリが issuer・scope・テナントを検証する」「古い鍵は使われない」[D] | Storm-0558、CVE-2025-55241 | consumer 鍵で署名した token が enterprise 向けに受理され、開発者はライブラリが完全に検証すると誤認していた [I][^2]。別テナントの token がレガシー API で受理された [I][^4] | CB-REQ-01〜06 |
| (b) 非本番・レガシー・内部経路が統制外 | 「テスト資産・旧テナント・内部 token は外から悪用されない」[D] | Midnight Blizzard、CVE-2025-55241 | MFA のない旧テストテナントと、高い権限を持つ旧テスト OAuth アプリが起点になった [I][^7]。発行ログのない内部 token が使われた（発見者の記述）[I][^4] | CB-REQ-06〜09 |
| (c) MFA 通過後の窃取 | 「MFA を通った session は正当」[D] | CircleCI、Okta、Snowflake | 2FA 済みの SSO session が盗まれた [I][^21]。HAR 内の session token が再利用された [I][^9]。infostealer で盗まれた資格情報が何年も有効なままだった [I][^13] | CB-REQ-11〜14、CB-REQ-20 |
| (d) support・ヘルプデスク経路 | 「サポート窓口は本人を識別でき、添付物に秘密はない」[D] | Okta、MGM／Scattered Spider、Salesloft Drift（Cloudflare の被害） | 攻撃者は従業員を装ってヘルプデスクにパスワードの再設定と MFA の移転をさせた [I][^22]。Salesforce のサポートケース本文に API token が含まれていた [I][^17] | CB-REQ-10、CB-REQ-19 |
| (e) 第三者連携の grant | 「連携事業者は token を安全に保管し、流出は個別の事象にとどまる」[D] | Salesloft Drift、Cloudflare 2023（上流の侵害の連鎖） | 連携事業者の環境から顧客連携用の OAuth token が取得され、多数の Salesforce から大量に export された [I][^15][^16] | CB-REQ-13、CB-REQ-15、CB-REQ-16 |
| (f) 可変属性による連結 | 「email は本人に固有で不変」「IdP の追加は無害な設定変更」[D] | nOAuth、Scattered Spider | 可変で未検証の email claim によってアカウントを乗っ取れた [I][^18]。攻撃者は federated IdP を追加し、自動連結を有効にした [I][^22] | CB-REQ-17、CB-REQ-18 |
| (g) 自社の変更・自動化が全域に及ぶ | 「自動処理は入力と保持指定を正しく扱う」「設定やデータは code ではないので段階展開しなくてよい」[D] | Google 2020、Azure AD 2021、Atlassian 2022、CrowdStrike 2024 | quota の自動化[I][^24]、鍵削除の自動化[I][^25]、削除スクリプト[I][^26]、content の配信[I][^27]が起点になった | CB-REQ-03、CB-REQ-23〜28 |
| (h) 検知とログ | 「自社のログで侵害を捉えられる」[D] | Storm-0558、Okta、Atlassian、CVE-2025-55241 | 有償ログが検知の鍵になった[I][^1]。別種のイベントのために 14 日間ダウンロードを特定できなかった[I][^9]。正規の workflow で削除されたため内部監視は検知しなかった[I][^26] | CB-REQ-21、CB-REQ-26 |

（g）と（h）は侵害と可用性の両方にまたがる [D]。同じ基盤を全サービスが使う構成（seed-03 D1）では、(a)〜(f) の侵害も (g) の障害も全テナントに同時に波及し得る [D]。このため本書の要件候補の多くは、「共通の契約・統制」は一つに保ちながら「共有される実装・鍵・障害範囲」を cell 単位に分けるという ADR-013 の原則に帰着する [D]（RS-12 §2-13、RS-09 §2-3 から導出）。

### 6.5 長く保つものと入れ替えを前提にするもの（G-073、R-209）

事故の教訓を、20 年の計画期間 [A-100] にわたって維持する原則と、入れ替えを前提に設計するものに分ける [D]。標準の世代交代の側からの分類は RS-11 と DL-47 が扱う [D]。

|---|---|---|---|
| 利用者の識別子は iss+sub（不透明・不変）だけに依拠する | 長く保つ | nOAuth | ADR-021、ADR-004 |

| 回復・support・ヘルプデスクを含め、主体の認証の強さを最も弱い経路で評価する | 長く保つ | MGM／Scattered Spider、Okta | ADR-003 |

| 認証器の方式（SMS・OTP からフィッシング耐性方式へ） | 入れ替え前提 | MGM／Scattered Spider、Snowflake | ADR-002 |
