## 要約

- 本書は、再提案の作業で検討して棄却した仮説・設計案・数値を、棄却理由・根拠・変えた設計・再検討条件とともに 1 か所に集めた記録である（DL-107）[D][^6]。
- 登録件数は **RH-001〜RH-215 の 215 件**である [D]。内訳は §1 に示す。§2 の 23 件が旧提案書からの主要な方針変更、§3 の 186 件が ADR-001〜ADR-029 の棄却案、§4 の 6 件が Wave A 文書（01〜03、06）で採らないと書いた案である [D]。
- 旧提案書からの方針変更のうち最も大きい 3 つは次のとおりである [D]。
  - access token 寿命の一律 5〜15 分（RH-001）を撤回し、token 種別×操作階層ごとに導出する方式（ADR-005 D3）に変えた [D]。
  - 全操作一律の fail-closed（RH-002）を撤回し、「不明なら deny」は維持したうえで、操作 5 分類ごとの fail-mode（ADR-013 D13-23〜D13-25）に変えた [D]。
  - 4 象限と参考ポジション表による自己評価・他社格付け（RH-003〜RH-005）を撤回し、性質の主張を「攻撃者モデル・統制・証拠・残余リスクの受容者」の形で書く規約に変えた [D][^1]。
- 同じ仮説が複数の ADR で棄却されている場合（例: trace id を access token に入れる案は 8 本の ADR が棄却）は 1 件の RH に統合し、出典欄に全ての出典を並べた [D]。統合の対応は §3 の各表の「→RH-xxx」行で辿れる [D]。
- 本書の棄却は、旧提案書のレビュー（CTO/CISO レビュー）の判定と、ADR 起草時の判定パネル（自己レビュー）の結果を記録したものであり、実在の CTO/CISO の決裁ではない [D][^1]。決裁事項に関わる棄却（閉じ方 B）は、DEC-1〜DEC-9 の決裁で覆り得る [D]。

## 0. 本書の位置付けと凡例

### 0.1 範囲

- 対象は次の 5 つの出典である [D]。
  1. 旧提案書[^2]の主張のうち、主張台帳[^4]が処置「削除」「要実測」とした 45 件、および旧提案書の「採用しない案」（L380〜L392）・「意思決定事項」（L394〜L405）・「4 象限マッピング」（L309〜L341）の全主張（G-008 の合格条件[^7]）。
  2. CTO/CISO レビュー[^3]の意思決定マトリクス（L221〜L233）が不承認・未承認・削除とした項目。
  3. ADR-001〜ADR-029 の「3. 検討した選択肢」と「5. 決定理由と棄却理由」で棄却した案。ADR 内で仮 ID（例: RH-001-A、H7-A、ADR-011/RH-01、H13-F1）が付いているものは出典欄にその仮 ID を残した [D]。
  4. 主要 ADR 8 本の整合調整記録[^5]で全 ADR に共通の結論とした棄却（trace id を claim に入れる案、属性を token に厚く載せる案、VC を token にする案）。
  5. Wave A 文書（01_governance、02_requirements、03_threat-model、06_controls）で「採らない」「採用しない」「推奨しない」と明記した案。
- 対象外とした範囲と理由は §7 に示す [D]。主なものは、Wave A 文書の決裁案で推奨しなかった選択肢（決裁前のため「棄却」とは扱わない）と、ADR の副論点のうち §5 の棄却表に載っていない選択肢である [D]。

### 0.3 記録の書き方

- 表のセルの主張にはタグを付けた。規範・ベンダー公開事実・事故報告の原典は脚注で示し、research/ の検証済み項目を RS-xx#n で併記した [D][^1]。
- 脚注 [^10] 以降は、出典 ADR の参考文献の記載（書誌、参照箇所、確認日）を転記したものである。原典の取得と照合は各 ADR の起草者が 2026-10-03〜2026-10-15 に行い、research/ の独立検証を経た項目には RS-xx#n を付けている [D]。本書の作成者は原典を再取得していない。RS-xx#n のない脚注（例: [^79] の RFC 7515 §5.2）は、ADR 起草者による確認だけで独立検証は未了である [D]。
- 「再検討条件」は出典 ADR の「この案が勝つ条件」「再評価の条件」「覆る条件」を要約したものである。詳細と監視の担当は各 ADR の §8（再検討トリガー）にある [D]。
- 前提値（A-xxx）は前提台帳[^9]の仮置き値である。本書で新たに置いた仮定はない [D]。
- 状態が変わり得る標準（Internet-Draft、NIST ipd）は、版・状態・確認日を脚注に記した [D]。standards-status.md を版・状態の正本とする [D]。
